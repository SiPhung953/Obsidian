#ObjectOrientedAnalysisAndDesign 
What are the main artifacts of Requirements? ^ff763a
- [[#^ff763a|Q1 answer]]
	- The main artifacts of Requirements are: The Use-Case Model (Consist of Use Cases Diagram and Use-case Specifications), the Glossary and the Supplementary Specification

What are the Requirements artifacts used for? ^87794f
- [[#^87794f|Q2 answer]]
	- The purposes of Requirements artifacts are:
		- To establish and maintain agreement with customers and stakeholders on what the system should do
		- Give developers a better understanding of the requirements of the system
		- Delimit (Determine the limits of) the system
		- Provide a basis for planning the technical contents
		- Provide a basis for estimating cost and time to develop the system
		- Define a user interface of the system

What is a Use-Case Model? ^9d778e
- [[#^9d778e|Q3 answer]]
	- A Use-case model is a model that describe a system's functional requirements in terms of use cases
	- It is a visual representation used to define a system's functional requirements by showing the interactions between users (the actors) and the system's function (the use cases) 

What is an actor? ^32a35b
- [[#^32a35b|Q4 answer]]
	- An Actor represents anything (users, hardware devices, other systems) that interacts with the system

What is a use case? List examples of use case properties. ^9079d4
- [[#^9079d4|Q5 answer]]
	- A use case is a sequence of actions a system performs that yields an observable result of value to a particular actor
	- Some use case properties are:
		- Name (E.g: "Login", "View Report Cards")
		- Description of the use case's purpose
		- Events flow - The sequence of actions that can be done
		- Relationship
		- Activity diagram
		- Use-case diagram
		- Special requirements
		- Pre-conditions
		- Post-conditions
		- Other diagrams

What is the difference between a use case and a scenario? ^8843e8
- [[#^8843e8|Q6 answer]]
	- An Use-case defines overall functionality and purpose from a user's perspective
		- has one linear flow of events with alternative flows (Include regular variants, odd cases, exceptional flows for handling error situations)
	- A Scenario defines a specific instance or path of a use case, detailing the steps involved in achieving the goal
		- is an instance of a use case

What is a Supplementary Specification and what does it include? ^d8f674
- [[#^d8f674|Q7 answer]]
	- A Supplementary Specification details a system's non-functional and system-wide requirements that are not included in other documents like Use-case Document
	- It include categories such as:
		- Performance
		- Reliability
		- Usability
		- Functionality
		- Supportability
		- Design constrain

What is a Glossary and what does it include? ^3d6b84
- [[#^3d6b84|Q8 answer]]
	- Is a list of technical terms and definitions specific to the system or subject area. It acts as a dictionary for the reader to understand special words or expression of particular profession.
	- A glossary can include:
		- Introduction: Paragraphs explaining the scope and purpose of the document
		- Terms: Specific words, phrases or abbreviations used within the document
		- Definition: Explanations of what each terms means
