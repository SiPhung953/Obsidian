### 1) Software Dev Problems
There are many problems within Software Development
E.g: User/Business needs not met, requirements not addressed, modules not intergrating (Not enough communication within team), difficulties with maintenance (no/poor documentation, difficult for other developer to fix), late discoveries of flaws
- When this happen, we have to trace symptoms to root cause, which could take some time
- So how do we not make these mistakes in the first place?

### 2) The Six best practices
##### Develop Iteratively
To develop iteratively is to break down the software development lifecycle into smaller chunks, upon finishing the the final chunk, we iterate/cycle back to the first chunk and work again.

Let's compare the characteristic of iterative development with the Waterfall model
- Waterfall model assumes that you have completed everything there is to a chunk. And when we are in a process, we cannot come back to the previous process
- This could potentially create many problems like
	- Delays confirmation of risk resolution, delays integration and testing
