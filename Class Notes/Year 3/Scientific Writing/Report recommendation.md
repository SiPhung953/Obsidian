Use Hierachy for top-down approach

Transition is needed
Example:
___
# Introduction
### 1.1) Context and motivation
Lorem ipsum
___
We can see that between the Introduction and the 1.1), there's no connection between the section and subsection, which can make people not following the context lost

Good example:
___
# Introduction
(Transition goes here, this part will detail the knowledge mentioned before that will be used here, and leading sentence to what you will say)
### 1.1) Context and motivation
Lorem ipsum
___

Do note that depending on the context of the paragraph, using "I" or "we" is important. It's usually recommended to use "we", or another way is to write in Passive Voice
